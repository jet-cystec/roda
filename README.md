# flow_cys Landing Page

Landing page oficial para **flow_cys**, el ecosistema de automatización inteligente de aprobaciones nativo de Google Workspace.

## 🚀 Descripción

Este proyecto es una **Single Page Application (SPA)** diseñada con un enfoque "Pixel Perfect", alto rendimiento y fidelidad a la marca **Cystec**. Su objetivo es presentar la propuesta de valor de flow_cys: automatización sin licencias adicionales y visibilidad total.

## 🛠️ Stack Tecnológico

*   **HTML5 Semántico**: Estructura optimizada para SEO.
*   **Tailwind CSS (vía CDN)**: Estilos utilitarios para diseño.
*   **Vanilla JavaScript**: Lógica ligera para interactividad.
*   **Lucide Icons**: Iconografía SVG moderna y ligera.
